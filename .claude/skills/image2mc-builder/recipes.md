# 部位ごとの作り方の辞書（どこに・どのブロックを・どの形で）

「赤いから red_concrete」のように色と種類だけで決めると、全部フルブロックの塊になって抽象的すぎる。
**部位ごとに、ブロックの形（フル／ハーフ上下／階段／柵／壁／板ガラス／トラップドア）、厚さ、重ね方、置き方**を決める。
出典: 実在の店舗（KFC 堺北花田）の写真を、Minecraft のブロックで描き起こした見本画像
（ユーザーのお手本 `examples/kfc_kitahanada/reference.webp`、部位の拡大は `examples/kfc_kitahanada/parts/`）。
**数（何マス・何段）は必ずお手本で数えて部位表に書く。この辞書の数は目安で、お手本と違えばお手本が正しい。**

## 使い分けの原則（どの部位にも）

1. **形と厚さを先に見る。色はその後。**
   - 厚さは、テクスチャの模様の列数か、隣のフルブロックとの高さの比で決める
     （例: `bricks` はフル1個で目地が4列。2列ならハーフ）
   - 候補の形: フル／ハーフ（上付き・下付き）／階段／柵／壁（塀）／板ガラス・鉄格子／トラップドア／ボタン・カーペット
2. **透けるものは透けるブロックで作る。** 柵・格子・ガラスの向こうが見えることが、その部位らしさになる。
   不透明な板を並べて代わりにしない。
3. **飛び出すものは壁から1マス出す。** 帯（軒）・看板の枠・立体文字。影ができて「付いている」ように見える。
4. **照明は吊るか、柱の上に置く。** 光るブロックを壁に埋めるだけにしない。
5. **色の対応表（`block_catalog.py`）は、模様の無い単色の部分だけに使う。** 模様のある物（レンガ・柵・格子）は、
   色だけで選ぶと別物になる。模様物は見た目で選ぶ。
6. **置く位置は、まわりの物から見てどこにあるかで決める。** 地面の何マス目かではなく、写真でその物に一番近い基準
   （土台・壁・天井・軒・植え込みの縁・角・扉）を見つけ、「何の、どちら側に、何マス」で部位表の「位置」に書く
   （例: 植え込みの外の縁に接する／壁から2マス外／軒の1マス下／北西の角から南へ2マス）。基準に接しているか、
   すき間があるか（何マスか）も写真で見る。基準を書かずに置いた物は、ずれても気づけない

## 手札（写真で見る所 → 選べる作り）

設計を書く前に、**この表の行を上から全部、写真と照らす**。行ごとに「写真で見た物」と「選んだ作り」を受け持ちの表（plan.md）の手札の表に書く。
写真に無い物は「無し」と書く（書かずに飛ばすと、型の作りや前の建物の作りがそのまま残る）。
どの作りにも当てはまらない物は、作りを決めずに質問する（0章）か、部品の不足として報告する。

| 部位 | 写真で見る所 | 手札（選べる作り） | 書く所 |
|---|---|---|---|
| 屋根 | 屋根の面が見えるか、傾きの向き | 平ら `{"type": "flat"}` ／ 四方に傾く `hip` ／ 二方向に傾く `gable`（法則4） | base.py の `ROOF` |
| 屋根の縁・屋上の物 | 屋根の縁に何が立っているか、向こうが透けるか。屋根から突き出た箱・看板の塔 | 何も無い（低い手すり壁だけ）／ 透ける柵（`lattice`、辞書「屋上の柵」）／ 板を並べたルーバー（`louver`）／ 箱・塔（`box_on_roof`、辞書「塔」） | パーツ（屋上） |
| 帯・軒 | 壁の上端に色の線があるか、厚さ（薄い線か、1段の厚みか）、壁より前に出ているか | 無し ／ 薄い帯が前に出る（`eave_slab` のハーフ、辞書「帯（軒）と軒天」）／ 厚い帯が壁と同じ面（STACK の `band` 段）／ 布のひさし（`frame+awning`） | base.py の `BAND`・`STACK`、パーツ（帯） |
| 壁の段 | 下から何が何段あるか（窓・無地・枠・帯） | 法則3 の表の型（店舗・ひさし付き・住宅の1階分・オフィスの1階分） | base.py の `STACK` |
| 窓 | どの面に、面のどこからどこまで | 面全体（`WINDOW_FACES`）／ 面の一部だけ（`window_strip`）／ 無し（無地の壁、辞書「壁（窓の無い面）」） | base.py・パーツ（面ごと） |
| 柱 | 窓の間の太い柱の間隔 | 何マスおき（`PILLAR_EVERY`）／ 角と入口の脇だけ（99） | base.py |
| 足元 | 壁の下にレンガ・石の帯や段があるか | 土台あり（`PLINTH = 1`）／ 無し（0。自動扉は付けられない） | base.py |
| 入口 | 扉の前の作り | 下の「入口の型の選び方」 | base.py の `ENTRANCE` |
| 看板・ロゴ・ポスター | 1枚ずつ、何に付いているか | 下の「看板の取り付け方」 | パーツ（看板1枚ずつ） |
| 外まわり | 建物のまわりの地面に立つ・置かれた物 | 植え込み（`planter` / `planter_ring`、辞書「植え込み」）／ 車止め（`bollard`）／ 木（`small_tree`）／ のぼり（`nobori`）／ 駐輪ラック（`bike_racks`）／ ポール（`pole`）／ 立て看板（辞書「立て看板」）／ 地面の張り替え（`ground`） | パーツ（外まわり） |
| 室内 | 窓の奥に何が見えるか | 机・椅子・吊り明かり（`furnish`。組み立て役が `WINDOW_FACES` に置く） | base.py の `WINDOW_FACES` |

## 入口の型の選び方

入口は**写真で、扉の前を人がどう歩いて入るか**を見て型を選ぶ（扉が見えない・2通りに読める時は、上から見た図の選択肢で聞く）。

| 写真で見えること | 型（base.py の `ENTRANCE`） |
|---|---|
| 扉の正面に、扉を隠す板・壁（ポスターや案内が付いていることが多い）があり、人はその左右から回り込んで入る。前に植え込みがある | **衝立つき** `kind="衝立つき"`（辞書「入口のまわり」。衝立にポスターがあれば `poster=True`） |
| 扉が壁の線にそのまま付いている、または柱に挟まれて少し凹んでいるだけで、正面からまっすぐ入る | **扉だけ** `kind="扉だけ"` |

型を決めたら、続けて次を写真で決める:
| 決めること | 写真で見る所 | 書き方 |
|---|---|---|
| 扉の種類 | ガラスの引き戸（店舗に多い）か、開き戸か | ガラスの引き戸なら `auto=True`（自動扉。`PLINTH = 1` が要る）、それ以外は `auto=False`（開口のまま） |
| 段 | 扉の前の段の数と形 | 段が無い・扉の前だけ1段（`steps="landing"`、辞書「扉の前の踏み台」）／ ハーフずつ上がる（`"slab"`）／ 階段（`"stairs"`） |
| 位置 | どの面の、左の角から何マスか | `face`・`door_k`（質問で聞く。0章） |
| 衝立つきの寸法 | 衝立の幅、左右の通路までの植え込みの幅、植え込みの右の端 | `screen_w`・`left_gap`・`right_gap`・`bed_end`（質問で聞く） |

入口の上のひさし・帯は「帯・軒」の手札で選ぶ（衝立つきは、帯を衝立の上まで自動で前に出す）。

## 看板の取り付け方

看板・ロゴ・ポスター・店名の文字は、**1枚ずつ、写真で「何に付いているか」を見て**取り付け方を選ぶ。
次の5つを1枚ずつ部位表に書いてから作る（分からなければ質問する）:
**① 何に付いているか ② 位置（まわりの物から見て: 何の、どちら側に、何マス。使い分けの原則6）③ 高さ（何の上に載るか・何の下か）④ 向き（読む人のいる方）⑤ 大きさ（人と比べて）**

| 何に付いているか（写真で見る所） | 取り付け方 |
|---|---|
| 壁に平らに貼ってある（文字だけ・薄いパネル） | `Facade(c, 面).at(k, out=1)`（壁の1マス外の額縁）、`BACKING` は None。文字だけなら背景を透明に（`sign_art.text`） |
| 壁から箱になって前に出ている（厚みのある看板） | `at(k, out=2)`、`BACKING` に箱の色のブロック（額縁の裏に置かれて、箱の厚みになる） |
| 屋上の塔・箱の面 | 先に塔（`box_on_roof`）を決め、その面に `at(k, out=1)`（ロゴを前に出すなら `out=2`）。高さは塔の段（`c.top` から何段目か）で書く。辞書「塔」 |
| 扉の前の衝立（ポスター） | 入口の型を「衝立つき」にして `poster=True`。位置は組み立て役が置き、パーツは絵だけを描く |
| 地面に自立している（足の付いた案内板） | 辞書「立て看板」（根元のマス・足は基本は細い柵1本・板の向き） |
| 高い柱の上（ポール看板。建物より高い・高さ6マス以上） | 太い足: `pole` で柱を立て、その上に看板（向きは道路の方） |
| 窓ガラスの内側に貼ってある | 小さな貼り紙は作らない。大きな物は、作り方を決めずに質問する（部品が無い） |

- **向き**は、読む人（歩道の人・ドライブスルーの車・道路）の方へ向ける。建物の正面とは限らない
- 絵は写真から中身（文字・色・形・配置）を読んで `sign_art` の型で描く（法則7、parts.md の「看板の絵」）

## 部位の辞書

### 植え込み（花壇）の縁
| 項目 | 作り方 |
|---|---|
| 縁 | **レンガの塀（`brick_wall`）かハーフ（`brick_slab`）で薄く、低く**。横から見て2段のフルブロックにならないこと |
| 中身 | 縁と縁の**間にブロックを入れて**砂利を表す（白い砂利なら `diorite`）。縁より高くしない |
| 置く所 | **建物の壁に沿ってだけ**。歩道の角や道の真ん中に箱を置かない（お手本に無い所に作らない） |
| 入口の脇 | 縁を入口の段に合わせて切る（入口をふさがない） |
| 切れ目と段 | **植え込みの切れ目や、縁に沿って上がる階段は「通路」**。飾りの段々ではない。KFC は左右2か所に通路があり、どちらも衝立（塀で囲ったポスター）の裏の1マスの通り道を通って扉へ行く |
| 部品 | `parts.planter_ring(c, select)`: 壁のすぐ外の1マスに砂利、その外を `brick_wall` で囲う（高さ1、端も閉じる） |
| よくある間違い | `bricks` のフルブロックを2段積んで囲う（横から見て塊になる）。歩道の角にはみ出した箱 |

### 入口のまわり（衝立つきの入口: 衝立・通り道・左右の通路）
| 項目 | 作り方 |
|---|---|
| 並び（手前→奥） | 植え込み・衝立（塀で囲ったポスター）→ 人1人分の通り道 → 扉。通路は衝立の左右から（数と位置は写真で、ユーザーに確かめる） |
| 床の高さ | 通り道と通路は**ハーフで底上げ**し、通路の入口で歩道から1段上がる。扉の床へもう1段。**横から見た高さの図を描いて決める** |
| 軒 | 帯（軒）を**衝立の上まで前に出して**、通り道と衝立を覆う |
| 衝立の高さ | **上は帯の真下まで**（帯との間にすき間を残さない）。ポスターは**植え込みの高さ（地面+1）を台にして、その上から**。足元の段に看板を置くと、沈んで見える |
| 衝立の前 | 植え込みを衝立の前にも通して、左右の通路のあいだを1本で囲う。ポスターの前に車止めを立てない |
| 通路と植え込みの端（ユーザーの手直し） | 通路は植え込みを切って通す（切り口は塀で閉じない）。植え込みと通り道の端は**建物まで塀で閉じ**、帯もその塀の上まで伸ばす。KFC の右の通路は衝立の1マス南 |
| 車止め（ユーザーの手直し） | 衝立の**両脇**（衝立の端の1マス外）と、植え込みの真ん中に、ランタンを載せた黒い塀 |
| 確かめ方 | 地面から積み上げた数ではなく、**帯の高さから下へ**、横から見た断面で数える |
| 部品 | 入口の型「衝立つき」（base.py の `ENTRANCE = dict(kind="衝立つき", ...)`）で、組み立て役が `parts.front_entrance` を呼んで一式を置く（この表の並び・高さ・順のまま）。衝立は帯の下で止まる物で、上の塔とはつながない |

### 自動扉の仕掛け
| 項目 | 作り方 |
|---|---|
| 隠し方 | **回路は完全に隠す**。ピストン・粉・トーチのまわりを石レンガ（`stone_bricks`）で天井まで埋める。木の板の枠にしない |
| 置き場所 | 配線は床下、トーチは床の中（ピストンの真裏の室内側）。見えてよいのは扉のガラスと感圧板だけ |
| 部品 | `parts.auto_door(c, door, face)`（包むブロックは `PAL["door_frame"]`、既定は `stone_bricks`） |

### 扉の前の踏み台（よく使う作り）
| 項目 | 作り方 |
|---|---|
| 形 | **扉の前の1マスだけフルブロック**（床と同じ高さ）。その手前はハーフで、歩道 → ハーフ → フルブロック → 扉、と半分ずつ上がる |
| 断面 | `歩道 ▁ ░ ░ ░ █ ｜扉` （░ = ハーフ、█ = フルブロック） |
| ブロック | 床のハーフと同じ素材のフルブロック（KFC は `brick_slab` の通路に、扉の前だけ `bricks`） |
| 部品 | `parts.entrance(..., steps="landing", step_slab="brick_slab")` |
| よくある間違い | 扉の前もハーフのままにする（扉の床とのあいだに半端な段が残る）。外の段を階段ブロックで作る |

### 入口の段と床
| 項目 | 作り方 |
|---|---|
| 段 | **ハーフ刻み**で上がる（`brick_slab` 等）。1段ずつフルで上げない |
| 床（入口の前） | 明るいタイル（`cut_sandstone` 等）。歩道と色を変えて、入口だと分かるようにする |
| 幅 | 入口の開口と同じか、それより広く |

### 帯（軒）と軒天
| 項目 | 作り方 |
|---|---|
| 帯 | **ハーフ（薄い横長）**。お手本でも写真でも帯は正方形ではなく横長で細い。フルブロックにしない。壁から外へ張り出す |
| 軒天（帯の下面） | 帯と壁の間の天井に、明るい灰色のハーフ（下から見上げたときに見える面） |
| 軒下の照明 | 小さい吊りランタンを等間隔。**ランタンを吊るために帯や軒天をフルブロックにしない**（吊る所が無ければ鎖で下げる） |
| 帯の飾り | 白い縦の線などは、帯のブロックをその色に置き換える |
| 部品 | `parts.eave_slab(c, slab)`: 壁から1マス張り出した下付きハーフ＋軒下の吊りランタン（下付きハーフの下面には吊れる） |
| 色の制約 | **赤いコンクリートにハーフは無い**。赤系のハーフは `mangrove_slab`（くすんだ赤）、`red_nether_brick_slab`（暗い赤）、`resin_brick_slab`（橙）。1つのマスにハーフは1種類なので、帯と軒天を同じマスに重ねられない |

### 屋上の柵（ルーバー・格子）
| 項目 | 作り方 |
|---|---|
| 柵 | **`nether_brick_fence` を3段**（KFC のお手本）。柵どうしがつながって横棒が6本になり、**向こうが透ける**。太い支柱は立てない |
| 高さ | 屋上から3段。**屋上より上の物は低い**（帯の上に5段も積まない） |
| よくある間違い | 不透明な板を並べる。支柱付きで5段以上積んで、2階建てのように見せる |
| 部品 | `parts.lattice(c, 3, "nether_brick_fence", skip=塔のセル)` |

### 塔（看板の塔）
| 項目 | 作り方 |
|---|---|
| 壁 | 黒レンガ（`deepslate_bricks`）。**大きな立方体にしない**: KFC のお手本は**高さ4 × 幅5 × 奥行2**。その横は屋上の柵が続く |
| 位置 | 看板の塔は**入口の真上（入口の中心に合わせる）**。角に寄せすぎない |
| ロゴの看板 | **正方形**。幅5の塔なら **3×3**（塔の幅の6割ほど）。壁から1マス飛び出させ、**上の端は塔の上端より1段上**に出す。中は地図アート（読んで描く） |
| 店名の文字 | **塔の幅いっぱい**（幅5の塔なら **5×2**）。ロゴの下、塔の下の2段に、背景の透明な白い文字を壁に直接 |
| 立体文字 | 白いブロックを壁から1マス飛び出させて、ドット文字（線の太さ1マス）。地図アートなら背景を透明にして壁に直接（`SIGN_BACKING` を `None`） |
| 部品 | `parts.box_on_roof(c, セル, 高さ, 素材)`。看板は `signs` の5番目に向き（`north` 等）を書けば**どの面にも置ける** |

### 店先の窓
| 項目 | 作り方 |
|---|---|
| ガラス | **板ガラス（`glass_pane`）**を3段の高さで大きく。フルブロックのガラスで厚くしない |
| 細い枠 | ガラスの間に黒い細い縦枠（`black_stained_glass_pane` 等の板）。2〜3マスおき |
| 太い柱 | 窓の区切りと角に、暗い石のフルブロック（`deepslate_tiles` / `polished_deepslate`）を帯の下まで |
| 上下 | 窓の上と下に、暗い枠を1段ずつ |
| 奥 | 室内が見える（下の「室内」） |
| 面の一部だけ窓 | `parts.window_strip(c, 面, k0, k1, rows=3, mullion=[縦枠の k])`（ほかは壁のまま。窓の無い面の角だけガラス、など） |

### 壁（窓の無い面）
| 項目 | 作り方 |
|---|---|
| 壁 | 横張りの板に見える明るい灰色（`smooth_stone` の縁取りが横板に見える） |
| 足元 | 1段だけ暗い灰色（`polished_andesite` 等）の帯 |
| 雨どい・凹み | 壁から1マス引っ込めた縦の列（`light_gray_concrete`） |
| 大きな看板 | 黒地の地図アートを壁に平らに付ける |
| 境の低い塀 | `stone_bricks` を4段ほど |

### 柱の上の明かり・車止め
| 項目 | 作り方 |
|---|---|
| 車止め | 黒い塀のブロック（`polished_blackstone_wall`）を1つ、砂利の上に3マスおき（`parts.bollard`）。お手本に明かりが無ければランタンは載せない |

### 立て看板（ドライブスルー等）
| 項目 | 作り方 |
|---|---|
| 向き | **案内する相手（ドライブスルーなら車の通路）の方を向ける**。KFC は建物の正面ではなく**横の面（車の通路側）から見える向き** |
| 枠 | 黒（`black_concrete`）1マス幅 |
| 面 | 地図アート（文字・矢印） |
| 足 | **1本**を板の真ん中の下に立てる。**基本は細い足**（柵を1本。色は写真に合わせて `spruce_fence`・`nether_brick_fence` など）。**太い足は、建物より高い看板か、高さ6マス以上の看板だけ**（塀 `polished_blackstone_wall` などを積む。ポール看板は `pole`）。人の背丈くらいの案内板は、写真で太く見えても細い足にする。フルブロックの柱にしない。2本にするのは、写真で足が2本見える時だけ |
| 根元 | **作り始める前に、根元がどのマスに刺さっているかを、まわりの物から見て決める**（使い分けの原則6）: 植え込みの砂利の中・地面・歩道のどれか、植え込みの**どちらの縁**に寄っているか（縁とのすき間は何マスか）、どの角から何マス・壁から何マス外か。写真で決められなければ質問で聞き、部位表の「位置」に「何から何マス」で書く。KFC は植え込みが北から西へ曲がる**角のマス**（建物の北西の角の斜め外）で、植え込みの外の縁とのすき間は無い。角・端・曲がり目は、写真で見つけやすい基準になる |
| 高さ | 板の下端は人の頭より上（地面+3）。足は根元から板の下まで |
| よくある間違い | 暗いフルブロックの柱を2本立てて、門の形になる。根元を決めずに板の位置から置き、足が通路や植え込みの縁に立つ。壁からのマス数だけで置き、植え込みの真ん中や壁寄りに立つ（写真では植え込みの外の縁に接していた） |

### 室内（窓から見える範囲）
| 項目 | 作り方 |
|---|---|
| 壁 | 白っぽいタイル（`white_terracotta` / `smooth_sandstone`）に、差し色（`red_concrete`）の大きなパネル |
| 天井 | 光る白い板（`sea_lantern` / `pearlescent_froglight`）を帯状に並べ、吊りランタンを足す |
| 家具 | 木の机とカウンター（`oak_planks` / `oak_slab`）、ベンチ（階段か上付きハーフ） |

## 見本画像から部位を読むときの手順

1. 部位ごとに **3〜6倍に拡大**する（`PIL` の `crop` → `resize(NEAREST)`）
2. その部位の **厚さ**（フル・ハーフ・板・柵）と **透け方**（透ける・透けない）と **飛び出し**（壁から出ているか）を書く
3. ブロックの種類は **テクスチャの模様**（レンガの目地、板の木目、石の縁取り）で決め、単色の部分だけ色の対応表で確かめる
4. この辞書の表に1行足す（部位・作り方・よくある間違い）
